# 🏥 Healthcare Analytics Dashboard

## Overview
The Healthcare Analytics Dashboard is a data visualization project developed using SQL Server and Power BI. The purpose of this project is to analyze healthcare data and provide meaningful insights into patient demographics, treatment outcomes, readmission rates, disease distribution, and medication usage.
The dataset was cleaned and transformed in SQL Server before being connected directly to Power BI for reporting and visualization.


## Tools Used
- SQL Server
- Power BI
- DAX (Data Analysis Expressions)


## Data Cleaning and Preparation
Data preprocessing was performed in SQL Server to improve data quality and ensure accurate reporting. The cleaning process included:
- Removing duplicate records
- Handling missing values
- Standardizing data formats
- Validating data consistency
- Preparing data for analysis and visualization


## Dashboard Features
### Key Performance Indicators (KPIs)
- Total Patients Count
- Readmission Rate
